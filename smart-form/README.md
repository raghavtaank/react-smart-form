
# React Smart Form

## About the Project
React Smart Form is a responsive form application built using React. It allows users to enter personal information, professional details, and preferences.The application includes form validation and record maanage using browser localStorage.

## Features
- Form input handling using React useState
- Form validation with error messages
- Multiple skills and contact methods selection
- Save submitted records in localStorage
- View, edit, and delete submitted records
- Automatically load saved records after page refresh
- Notifications preference toggle switch
- Submit and update records
- Responsive design for mobile and desktop

## How to Run the Project
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown in the terminal.
